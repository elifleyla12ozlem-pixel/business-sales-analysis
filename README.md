# Sales Performance & Business Analysis

## Overview
A Python-based business analysis project that evalutues sales performance, revenue profit, and product profitability.

## Features
- Sales revenue and profit calculations
- Product performance analysis
- Business insights and recomandations
- Sales performance visualazitons
- CSV report generations
- Pdf report generation
- Basic data validation

## Technologies
- Python
- Pandas
- Mathplotlib
- ReportLab
- Google Colab

## Outputs
- Product performance chart
- CSV analysis report
- PDF business report

## Purpose
This project demonstrates practical data analysis, business reporting,and basic decision-spport skills.
